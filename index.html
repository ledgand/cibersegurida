01 — CONCEPTO

¿Qué es la ciberseguridad?

La ciberseguridad es el conjunto de tecnologías, procesos y prácticas utilizadas para proteger sistemas informáticos, redes, dispositivos y datos frente a ataques digitales.

Su objetivo es mantener la información segura, confidencial y disponible para las personas y organizaciones.

🛡️

Protección digital

Seguridad + Privacidad + Disponibilidad

02 — AMENAZAS

Principales ciberamenazas

🦠

Malware

Software malicioso diseñado para dañar, alterar o acceder sin autorización a sistemas.

🎣

Phishing

Técnica utilizada para engañar a las personas y obtener información confidencial.

🔒

Ransomware

Ataque que cifra archivos y exige un pago para intentar recuperar el acceso.

🌐

DDoS

Ataque que busca saturar un servicio mediante una gran cantidad de solicitudes.

👤

Ingeniería social

Manipulación de personas para conseguir información o acceso a sistemas.

🔑

Robo de credenciales

Obtención ilícita de contraseñas y cuentas mediante diferentes técnicas.

03 — HERRAMIENTAS

Herramientas de ciberseguridad

01

Nmap

Herramienta para descubrir dispositivos, servicios y puertos en una red.

02

Wireshark

Analizador de tráfico de red utilizado para estudiar paquetes.

03

Kali Linux

Distribución orientada a pruebas de seguridad y análisis de sistemas.

04

Metasploit

Framework utilizado para investigación y pruebas de seguridad autorizadas.

04 — PROTECCIÓN

¿Cómo protegerte?

01

Usa contraseñas fuertes

Utiliza contraseñas largas, únicas y difíciles de adivinar.

02

Activa MFA

Utiliza autenticación multifactor cuando el servicio lo permita.

03

Actualiza tus dispositivos

Mantén actualizado el sistema operativo y tus aplicaciones.

04

Evita enlaces sospechosos

Verifica el remitente y la dirección antes de hacer clic.

05

Realiza copias de seguridad

Mantén respaldos de información importante.

06

Protege tu Wi-Fi

Utiliza una contraseña segura y configura correctamente tu router.

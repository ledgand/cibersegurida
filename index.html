02 — AMENAZAS

Conoce los principales ciberataques

01
🦠

Malware

Software malicioso diseñado para dañar, alterar o acceder sin autorización a sistemas informáticos.

02
🎣

Phishing

Ataques que utilizan mensajes o sitios falsos para intentar obtener información confidencial.

03
🔒

Ransomware

Malware que puede cifrar archivos y bloquear el acceso a información.

04
🌐

DDoS

Ataques que buscan afectar la disponibilidad de un servicio mediante numerosas solicitudes.

05
👤

Ingeniería social

Manipulación de personas para obtener información o conseguir acceso.

06
🔑

Credenciales robadas

Obtención de nombres de usuario y contraseñas mediante diferentes técnicas.

03 — HERRAMIENTAS

Tecnologías de ciberseguridad

01

Nmap

Herramienta utilizada para descubrir dispositivos, servicios y puertos en redes.

nmap -sV target
02

Wireshark

Analizador de tráfico de red que permite estudiar paquetes y comunicaciones.

packet_analysis
03

Kali Linux

Sistema operativo utilizado para auditorías y pruebas de seguridad autorizadas.

kali@linux:~$
04

Metasploit

Framework utilizado para investigación y pruebas de seguridad en entornos autorizados.

security_testing

04 — PROTECCIÓN

Protege tu información

01

Contraseñas seguras

Utiliza contraseñas largas, únicas y difíciles de adivinar.

02

Autenticación multifactor

Activa MFA siempre que esté disponible para añadir una capa adicional.

03

Actualizaciones

Mantén actualizado tu sistema operativo y tus aplicaciones.

04

Evita el phishing

Comprueba cuidadosamente los enlaces y remitentes antes de responder.

05

Copias de seguridad

Realiza respaldos periódicos de información importante.

06

Protege tu Wi-Fi

Utiliza una contraseña segura y configura correctamente tu router.
